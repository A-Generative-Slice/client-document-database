# Client Folder Template

This is a template structure for new client folders. Copy this structure when adding a new client.

## 📁 Directory Structure

```
<client-name>/
├── data/          # JSON data files for document generation
├── generated/     # Generated HTML documents (working files)
└── signed/        # Final signed PDF documents (source of truth)
```

## 🚀 Quick Start

### 1. Create a New Client Folder

```bash
# Copy this template
cp -r clients/_template clients/your-client-name

# Or create manually
mkdir -p clients/your-client-name/{data,generated,signed}
```

### 2. Prepare Data Files

Create JSON data files in the `data/` directory:

```bash
# Example: Invoice data
vim clients/your-client-name/data/invoice-project-name.json
```

### 3. Generate Documents

```bash
node scripts/generate-document.js invoice your-client-name clients/your-client-name/data/invoice-data.json
```

### 4. Validate Documents

```bash
node scripts/validate-document.js clients/your-client-name/generated/Invoice_INV-XXXX.html
```

### 5. Export to PDF

1. Open the generated HTML in a browser
2. Use Print function (Ctrl+P / Cmd+P)
3. Save as PDF
4. Get client signature
5. Move signed PDF to `signed/` directory

## 📋 Naming Conventions

### Client Folder Names
- Use lowercase with hyphens: `client-company-name`
- Examples: `nas-design-construction`, `acme-corporation`, `tech-solutions-inc`

### Data Files
- Descriptive names: `invoice-project-name-date.json`
- Examples: 
  - `invoice-website-redesign-2026-04.json`
  - `maintenance-agreement-2026.json`
  - `signoff-website-launch.json`

### Generated Documents
Auto-generated by scripts:
- `Invoice_INV-1001.html`
- `Maintenance_Agreement_SLA-2026-001.html`
- `Project_SignOff_CERT-2026-001.html`

### Signed PDFs
Add "_SIGNED" suffix:
- `Invoice_INV-1001_SIGNED.pdf`
- `Maintenance_Agreement_SLA-2026-001_SIGNED.pdf`
- `Project_SignOff_CERT-2026-001_SIGNED.pdf`

## 🗂️ File Organization Tips

1. **Keep data files** - Store all JSON data files for future reference
2. **Version control** - Commit generated HTML files to Git
3. **Backup signed PDFs** - These are the legal source of truth
4. **Document history** - Keep a README.md in each client folder with project notes

## 🔒 Important Files

### `data/` Directory
- Contains source JSON files
- Keep these for record-keeping
- Use for regenerating documents if needed

### `generated/` Directory
- Working HTML files
- Can be regenerated from data files
- Good for version control

### `signed/` Directory
- **MOST IMPORTANT** - Legal source of truth
- Final signed PDFs
- Must be backed up
- Never regenerate without client approval

## 💡 Best Practices

1. **One client per folder** - Don't mix multiple clients
2. **Consistent naming** - Follow the conventions above
3. **Document everything** - Add README files with context
4. **Version control** - Commit changes regularly
5. **Backup signed PDFs** - Store in multiple locations
6. **Archive old projects** - Move completed projects to an archive folder if needed
